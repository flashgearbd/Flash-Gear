# FLASH GEAR BD — Final Professional Website

## Product management
The website reads products from the Google Sheets API already configured in `app.js`.

Google Sheet tab: `Products`

## Homepage categories
- Feature Phone
- Mobile Phones
- Adapter & Cable
- Charger
- Earbud
- Headphone
- Neckband
- Earphone
- Speaker
- Powerbank
- Smart watch
- Tripod
- Boya
- Screen Protector
- Phone Case

The website also automatically shows any additional category that appears in the sheet.

## Product fields
Product ID, Product Name, Category, Brand, Price, MRP, Stock, Warranty, Image URL, Description, Featured, Active

Use `Active = Yes` to publish a product.

## Features
- Professional dark/neon-blue mobile-first storefront
- Large technology hero visual
- Category cards with local product-category artwork
- Google Sheets-powered catalog
- Search and category filtering
- Price sorting
- Product quick-view/details modal
- Warranty and description display
- Local shopping cart
- WhatsApp direct order
- WhatsApp cart checkout
- Responsive Android/mobile layout
- Warranty, Delivery and Contact pages
- Local logo and visual assets
- No paid frontend services required

## Deploy
Upload all files in this folder to the root of the GitHub repository used by the Cloudflare Worker.
